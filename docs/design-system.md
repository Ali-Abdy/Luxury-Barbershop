# Design System

## Overview

This design system provides a premium, reusable visual language for the luxury barbershop experience. It focuses on accessible, typed components that feel refined and minimal without relying on template-heavy patterns.

## Tokens

- Colors: background, surface, elevated, border, muted border, primary and secondary text, accent gold, success, warning, danger, info, hover, focus, overlay.
- Typography: display, heading, body, small, caption, button.
- Spacing: 4, 8, 12, 16, 24, 32, 40, 48, 64, 80, 96, 128.
- Radius: small, medium, large, extra large, full.
- Shadows: small, medium, large, extra large.
- Motion: fast, medium, slow.

## Usage

Use the primitives in the UI layer for all future screens. Prefer server components for static content and reserve client components for interactions such as menus, selection, and theme switching.
