# Animation Library

The animation layer is built with Framer Motion and uses reduced-motion-aware helpers.

## Principles

- Keep motion subtle and purposeful.
- Prefer fade, lift, and scale transitions for interface polish.
- Respect the user preference for reduced motion.

## Available helpers

- FadeUp
- FadeDown
- FadeLeft
- FadeRight
- Scale
- Zoom
- Stagger
- Parallax
- PageTransition
- HoverLift
- ImageReveal
- TextReveal
